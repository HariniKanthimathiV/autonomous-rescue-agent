How to use

1. Choose a tool and tap grid cells.

2. Place at least one person and an exit. Set the agent start position too.

3. Click Run mission. The agent rescues people in turn, then navigates to the exit.

4. If no safe route exists, the log reports it. Hazards are treated as blocked cells.
